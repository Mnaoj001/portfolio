# Manoj D - Interactive Developer Portfolio & CV 🚀

A modern, interactive developer portfolio showcasing technical competencies in **Cyber Security**, **Data Science**, **Python**, **Java**, and **SQL**. Built with React, TypeScript, Tailwind CSS, and Framer Motion.

## 🌟 Live Demo
- **Portfolio**: [Check Deployment](https://github.com/Mnaoj001/portfolio)
- **Featured Live Project (Scam Shield 2.0)**: [scam-shield-three-roan.vercel.app](https://scam-shield-three-roan.vercel.app/)

---

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS + Custom Glassmorphism
- **Icons**: Lucide React
- **Animations**: Framer Motion + Canvas Confetti
- **Deployment**: Vercel / GitHub Pages ready

---

## ✨ Features
- **3D Tilt Interactive Cards**: Physics-based 3D card tilt and specular glare reflections.
- **Interactive CV Modal**: One-click printable ATS-compliant resume with direct **Print / Save as PDF** support.
- **Dynamic Terminal Typing**: Animated headline showcasing core engineering roles.
- **Theme Color Customizer**: Switch between Indigo, Cyan, Emerald, Purple, and Rose accents in real-time.
- **Live Scam Shield Showcase**: Direct integration of deployed Scam Shield 2.0 security app.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Mnaoj001/portfolio.git

# Navigate to project folder
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
```
